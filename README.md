# Goblin vs Unicorn — public game reference

Read-only reference for **Goblin vs Unicorn**, a Godot 4 mobile game that blends Puzzle & Dragons-style tile matching with a short, autonomous RTS battle phase. These files are regenerated from the game itself, so they reflect its current state.

| File | What it is | Read it for |
|---|---|---|
| [`game-snapshot.md`](game-snapshot.md) | Rules as built + current numbers (units, costs, terrain, economy), open questions | **Start here** — how the game works *today* |
| [`GameDesignDoc.md`](GameDesignDoc.md) | The written design intent (source of truth for how the game *should* work) | Design feedback, intent |
| [`ROADMAP.md`](ROADMAP.md) | Status, build order, bug list and decisions log | What's built, what's next, why |
| [`game-data.json`](game-data.json) | Raw numbers exported from the game's data files | Exact stats and costs |

Tags in the docs: **built** / **planned** / **idea** / **cut**. Numbers marked as assumptions are unmeasured guesses, not playtest results.
